## Descripción
El proyecto analiza factores académicos y socioeconómicos relacionados con la deserción y el éxito académico universitario.

Se utiliza una base de datos de UCI con 4424 estudiantes y 37 variables.

El análisis se realizó en RStudio mediante procedimientos de auditoría, preparación de datos y análisis exploratorio.
